# Security

At the Dutch Electoral Council (Kiesraad), we consider security to be important.
All reports related to security are therefor, of course, very welcome.

## Reporting a security issue
We appreciate it if you report (serious) security issues in a responsible manner
(i.e. not publicly), according to *responsible disclosure* principles. To report
a security issue, you can contact our CISO directly via security[@]kiesraad.nl.
